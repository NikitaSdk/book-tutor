# Book Tutor — читалка PDF, связанная с Claude

Читаешь книгу в браузере, а Claude (в приложении Claude Desktop, по твоей подписке) видит,
какую главу ты открыл и что выделил: делает выжимки, объясняет, создаёт тесты и проверяет ответы.
Всё сохраняется как заметки к книге.

## Установка (один раз)

1. Установи **Python 3.10+** с python.org. При установке поставь галочку **Add Python to PATH**.
2. Распакуй эту папку туда, где она будет жить постоянно (например, `C:\BookTutor`).
   Не перемещай её после установки, иначе нужно запустить установку заново.
3. Дважды щёлкни `install.py` (или в командной строке: `python install.py`).
4. **Полностью перезапусти Claude Desktop**: значок в трее → Quit, потом открой снова.
5. Проверь: Settings → Developer, там должен быть `book-tutor` со статусом running.

## Как пользоваться

1. Положи PDF в папку `books`.
2. Напиши Claude: **«открой читалку»** (или открой http://localhost:8765 сам).
3. Выбери книгу сверху, читай.
4. Пиши Claude в обычном чате:
   - «сделай выжимку главы, которую я читаю, и сохрани»
   - «выпиши все определения из этой главы»
   - «объясни выделенное» (сначала выдели текст в книге)
   - «сделай тест из 8 вопросов по этой главе, половина открытых»
   - «проверь тест» — после того как ответишь в читалке
   - «сделай тест по моим ошибкам»
   - «где в книге говорится про …?»

Вопросы с вариантами проверяются сразу, открытые («объясни своими словами») проверяет Claude.

## Что внутри

| Файл | Что делает |
|---|---|
| `server.py` | MCP-сервер для Claude + веб-сервер читалки + база `library.db` |
| `web/index.html` | Интерфейс читалки (PDF.js лежит в `web/vendor`, интернет не нужен) |
| `install.py` | Ставит библиотеки и подключает сервер к Claude Desktop |
| `library.db` | Появится сам: заметки, выделения, тесты, ответы |

Проверить читалку без Claude: `python server.py --web-only`.

## Если что-то не так

- **Claude не видит инструменты**: перезапусти Claude Desktop через Quit, а не крестиком.
  Посмотри лог в Settings → Developer → book-tutor.
- **Читалка не открывается**: она работает, только пока запущен Claude Desktop.
- **Claude говорит, что текста нет**: PDF — это скан без текстового слоя. Его сначала нужно распознать (OCR).
- **Порт 8765 занят**: в конфиге Claude добавь в блок book-tutor `"env": {"BOOK_TUTOR_PORT": "8777"}`.
